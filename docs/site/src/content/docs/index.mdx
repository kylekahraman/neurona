## Start small, compose as needed

A few constructors are enough for a simple drawing. Cells, custom paths, layer
stacks, abstract nodes, equation blocks, population boxes, and connections share the same circuit canvas.
Typst handles the text, and CeTZ supplies the vector drawing backend.

This documentation describes the **development version**. Download the starter
from [Installation](/neurona/getting-started/installation/) to try it today.
Typst Universe publication is tracked under [Development](/neurona/development/).
