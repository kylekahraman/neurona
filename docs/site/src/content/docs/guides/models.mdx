## Layers and representations

Use `model-layer` for the perspective planes seen in architecture figures.
Control the plane count, face dimensions, slant, dot grid, and colors.
Plane and dot counts are schematic; add actual model dimensions as labels.

<Example name="network-architecture" collapsed architecture />

Start with two layers in a file beside `lib.typ`:

```typst
#import "lib.typ": diagram, model-layer, link
#set page(width: auto, height: auto, margin: 5mm)
#diagram(
  nodes: (
    model-layer("input", at: (0, 0), planes: 1, body: [$x$]),
    model-layer("hidden", at: (3.5, 0), planes: 4, body: [$h$]),
  ),
  connections: (link("input.east", "hidden.west"),),
  width: 100mm,
)
```

`at` places the front face's center. Coordinates increase right and up;
dimensions use canvas units (`unit: 1cm` by default). `diagram(width: ...)`
sets the complete figure's physical output width, including its labels.

## Typography

The model examples use Inter for labels. The starter includes the font and
its open license in `fonts/`. With the CLI, add `--font-path fonts`:

```sh
typst compile --root . --font-path fonts examples/feedback-model.typ feedback-model.pdf
```

The drawing functions inherit the document font; use `#set text(font: "Inter")`
to apply it to your own labels. Mathematical notation retains its math font.

## Connections and composition

`link` draws a directed signal-flow arrow. Use `dashed: true` to distinguish
feedback and `directed: false` for unmarked relationships. `label: [$W$]`
adds a mathematical label. Routes accept either `via` waypoints or one/two
Bezier `controls`; position them explicitly to leave room around components.

Every node has directional ports such as `east`, `west`, `north`, and `south`.
On perspective layers these follow the actual front/rear plane geometry.
Custom `ports` specify offsets from the component center when a model needs
separate inputs or outputs.

Use `diagram` to combine activity planes, blocks, circular states, biological
cells, and regional layers on the same canvas. All connectable elements need
unique IDs. Use `projection` for a biological connection with an excitatory
arrow or inhibitory bar.

See the [Models API](/neurona/reference/models/) for parameters and port
positions, and [Styling and export](/neurona/guides/styling-and-export/) for
PDF, SVG, and PNG output.
