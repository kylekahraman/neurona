## Read the drawing

- `circuit` creates the canvas and composes its contents.
- `neuron("pc")` adds a pyramidal cell. The ID `pc` lets connections refer to it.
- `label: [Pyramidal cell]` supplies normal Typst content.
- `width: 60mm` scales the complete artwork to a physical width.
- `#set page(...)` crops the document around the figure with a small margin.

The trailing comma in `(neuron("pc"),)` makes a one-item list in Typst.

## Make a change

Replace the label with `[My cell]`. Then add `color: rgb("367c9e")` to the
`neuron` call. Compile again:

```sh
typst compile --root . examples/figure.typ figure.pdf
```

Try `detail: "branched"` for more branch detail, or `kind: "granule"` for a
different glyph. [The cells guide](/neurona/guides/cells/) explains those choices.
