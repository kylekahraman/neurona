# Tutorial sources and release plan

The documentation site now lives in [`../site/`](../site/README.md) and uses
Astro Starlight. Its build includes the six complete `tutorial/*.typ` examples
from this directory and generates their previews and downloads from source.

`RELEASE-PLAN.md` records the path to the first Typst Universe submission.
The former standalone tutorial page has been replaced by the Starlight
getting-started pages, guides, gallery, and API reference.
