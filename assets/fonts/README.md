# Figure font

Inter Regular 4.1, from https://github.com/rsms/inter/releases/tag/v4.1.
Distributed under the included SIL Open Font License (OFL.txt).

The font is used by the model examples and copied into the documentation
starter. It is not part of the Typst package runtime. To compile examples
from this checkout, add `--font-path assets/fonts` to the Typst command.
Drawing functions inherit the surrounding document font.
