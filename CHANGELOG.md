# Changelog

## 0.1.0 — release candidate

The first public release is being prepared; it is not on Typst Universe yet.

- Abstract model diagrams with equation blocks, circular states, named ports,
  background groups, neutral directed links, and mixed biological components.
- Worked examples for feedback across time, rate equations, latent-state models,
  and a neural network architecture.
- Experimental stimulus panels, proportional timelines, time axes, and lanes.
- Schematic cell glyphs, custom neurite paths, and named compartment ports.
- Independent regional layer stacks, optional cortical presets, and legends.
- Explicit projections, population boxes, annotations, and axon junctions.
- Four CA1 interneuron drawing recipes and three editable circuit motifs.
- Compact default cell detail, corrected tuft geometry, and clearer example
  connection routes; additional branching is available with `detail: "branched"`.
- Starlight documentation, visual gallery, source/SVG downloads, and a starter.
- Tested on Typst 0.13.1 and 0.15.0 with isolated package-import checks.
